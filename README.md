# 🌦 Weather App

A simple and responsive weather web application built using **HTML, CSS, and JavaScript**. It fetches real-time weather data using the **OpenWeatherMap API** and displays current weather conditions for any city.


##  Features

-  Search weather by city name  
-  Real-time temperature display  
-  Weather condition description  
-  Humidity information  
-  Wind speed details  
-  Beautiful animated UI with glassmorphism design  
-  Fully responsive design (mobile + desktop)


##  Technologies Used

- HTML5  
- CSS3 (Animations + Glassmorphism UI)  
- JavaScript (Fetch API)  
- OpenWeatherMap API
